## Purpose

These assets support local token counting and context-window
budgeting in QuestForge.

The tokenizer and configuration files are unmodified copies
from the pinned upstream revision.

Their SHA-256 hashes match the corresponding tokenizer
assets previously validated against Qwen2.5-3B-Instruct.

No model weights are included.

## Integrity

Run the following command from this directory:

    sha256sum -c SHA256SUMS
